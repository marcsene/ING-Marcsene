# ING.Marcsene

Software SaaS para la gestión de pequeños negocios.

## 🎯 Propósito

ING.Marcsene busca centralizar la gestión de productos, inventario, ventas,
clientes y análisis del negocio en una plataforma moderna y escalable.

## 🚀 Roadmap

### FASE 1 — MVP
- Login
- Crear negocio
- Productos
- Categorías
- Inventario
- Ventas
- Dashboard

### FASE 2 — Gestión
- Clientes
- Usuarios y roles
- Reportes
- Exportación Excel/PDF
- Multiempresa

### FASE 3 — SaaS
- Aplicación móvil
- Suscripciones
- Pagos
- Notificaciones

### FASE 4 — IA
- Predicción de ventas
- Recomendaciones de inventario
- Análisis automático del negocio

## 🏗️ Arquitectura

progresivamente como producto SaaS.
